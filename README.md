# 6-DOF Aircraft Flight Simulator

A 3D aircraft flight simulator developed using **Python** and the **Ursina Engine**, implementing 6-DOF equations of motion and aerodynamic forces and moments to simulate aircraft motion interactively.

The project combines aerospace engineering fundamentals, flight dynamics, numerical modeling, and real-time 3D visualization in a Python-based simulation environment.

## Features

- **6-DOF Flight Dynamics:** Models aircraft translational and rotational motion using six-degree-of-freedom equations of motion.
- **Aerodynamic Forces and Moments:** Incorporates aerodynamic forces and moments into the aircraft's motion model.
- **Interactive Flight Controls:** Control aircraft pitch, roll, and yaw.
- **Real-Time Telemetry:** Displays flight parameters, including altitude, velocity, and aircraft attitude.
- **Dynamic 3D Visualization:** Updates aircraft position and orientation in a 3D environment.
- **Keyboard and Joystick Input:** Supports interactive control through keyboard or joystick input.
- **Python-Based Implementation:** Uses Python for simulation logic and Ursina for 3D visualization.
